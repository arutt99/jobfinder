# Decisions and known limits

- Follow the uploaded plan's React/TypeScript/Vite/Pages design; no separate hosted service, account system, AI API, database or application submission.
- Node 24 is pinned across local and CI use. Dependencies use exact versions and a package lock. Runtime/build packages were checked against the actual install/typecheck/test/build process; audit fixes were applied before handoff. Fonts are bundled, so the app works without a font CDN.
- Use the existing `arutt99/jobfinder` repository and `/jobfinder/` project-path test, while Pages obtains its real base path from configure-pages. No remote settings/source approvals were invented.
- No country, currency, residence, employment eligibility, salary floor or live employer board is assumed. Salary controls initially select USD/year for comparisons only; no salary minimum is applied. All comparable pay units remain explicit.
- Source registry is empty by default; the example is disabled. Fourteen original synthetic jobs exercise the UI; every fixture job carries `synthetic: true`, and the manifest and UI explicitly label demo mode. Production staging and state-push reject demo data unless the local stage operation explicitly opts in; production workflow never opts in.
- Rule weights and thresholds are in `config/scoring-rules.json`. A broad systems title with ownership can rank as related (up to 55 points from responsibilities under these weights). Exact administrator titles alone score 50; responsibility evidence makes them strong. Do not change weights to conceal this scoring behavior.
- Strong destination-based cross-source dedupe is implemented. Shared employer/title fuzzy matches are only hints. There is no speculative shared-requisition merge, full-body similarity store, or split migration UI.
- Career-page support is fixture-tested JSON-LD for one reviewed URL, not a general crawler or arbitrary selector parser. Dynamic browser extraction, Workday/iCIMS/SmartRecruiters-specific adapters, optional aggregator credentials, and Internet-wide employer discovery are outside actual verified coverage.
- Ashby compensation summaries are retained as text when permitted; numeric structured-tier ranges stay unknown. No guessed annualization, currency conversion, sponsorship, clearance, country parsing or remote eligibility.
- Registry review and publication rights are configuration requirements from the user's build plan. There is no extra conversational approval gate for local development. Sources requiring finite retention are rejected because this public Git history cannot honor deletion of previous commits.
- Source health is deliberately safe and generic for provider parse/network errors; raw exception bodies and credential-bearing URLs are not logged. The HTTP client does not follow redirects automatically.
- Browser state supports a pre-release v0 map migration, current v1 backups, aliases, validation, newest-update merges, and memory fallback. Manual roles stay in the browser. Backup import previews a merge; it does not silently replace newer local updates.
- The browser recomputes stale/overdue labels once per minute. The six-hour UTC workflow is a best-effort schedule. Two/three successful full absences produce possibly-closed/closed, and a default 90-day retention applies to current closed records, not historical Git deletion.
